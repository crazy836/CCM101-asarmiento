# Laboratory Activity 1 - Welcome to the Cloud

## Mission Overview

The purpose of this laboratory activity is to introduce the Linux operating system and cloud computing environment using the KillerCoda Playground. The activity also focuses on creating a professional GitHub portfolio that will be used to store all cloud computing laboratory activities throughout the semester.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed

- Launched the Ubuntu 24.04 Playground in KillerCoda.
- Created a new Linux user with a home directory and Bash shell.
- Logged into the new user account.
- Gathered system information including Linux distribution, kernel version, CPU, memory, and disk space.
- Created folders and Markdown files for documentation.
- Built a GitHub repository named **CCM101-asarmiento**.
- Organized files according to the required repository structure.

## Linux Commands Used

| Command | Purpose |
|---------|---------|
| `whoami` | Displays the current user. |
| `pwd` | Shows the current working directory. |
| `hostname` | Displays the computer hostname. |
| `cat` | Displays the contents of a file. |
| `uname -r` | Shows the Linux kernel version. |
| `lscpu` | Displays CPU information. |
| `free -h` | Shows memory usage. |
| `df -h` | Displays available disk space. |
| `mkdir` | Creates directories. |
| `cd` | Changes directories. |
| `nano` | Creates and edits text files. |
| `ls` | Lists files and folders. |

## Skills Learned

Through this laboratory activity, I learned how to use basic Linux commands, create and manage users, navigate the Linux file system, collect system information, organize files and directories, write documentation using Markdown, and create a GitHub repository for maintaining a cloud computing portfolio.

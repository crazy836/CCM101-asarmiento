# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It allows users and organizations to access computing resources and services through the internet instead of depending only on their own physical servers.

Based on my understanding, Azure is useful because it provides many tools that can be used to develop, deploy, and manage applications. It supports different types of workloads, including websites, databases, virtual machines, artificial intelligence, and business applications. I also think Azure is especially useful for organizations that are already using Microsoft products because Azure works well with the Microsoft ecosystem.

As an IT student, I see Azure as a platform that can help me understand how companies move their applications and infrastructure from physical computers to cloud environments.

## 2. Global Infrastructure

Microsoft Azure has a large global infrastructure made up of regions and datacenters. Microsoft currently states that Azure has **80+ regions and 500+ datacenters** around the world. These locations allow organizations to choose where their applications and data should be hosted.

I think having many regions is important because businesses may have customers from different countries. By choosing an appropriate Azure region, a company can place its applications closer to its users and consider requirements such as performance, availability, and data residency.

For example, if a company has customers in Asia, it can consider an Azure region that is geographically closer to those customers instead of hosting everything on a server located far away.

## 3. Cloud Management Console

The main management interface for Azure is called the **Azure Portal**. It is a web-based console that allows users to create, manage, and monitor Azure resources through a graphical interface. Users can manage services such as virtual machines, databases, web applications, storage, and networks from the portal.

As a student, I think the Azure Portal is helpful because it gives a visual way of understanding cloud computing. Instead of only typing commands, I can see the available services and resources and learn how they are connected.

The portal also provides dashboards that can be customized to organize and monitor cloud resources.

## 4. Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtual computers that can run Windows or Linux operating systems in the cloud. I understand this service as basically renting a computer through the cloud instead of buying a physical computer or server.

For example, a company could create a virtual machine to host a website, application, or internal business system.

### 2. Azure Blob Storage

Azure Blob Storage is a cloud storage service designed for storing large amounts of unstructured data. This can include images, videos, documents, backups, and other files.

I think this would be useful for applications that allow users to upload files because the files can be stored in the cloud rather than directly on the application's server.

### 3. Azure SQL Database

Azure SQL Database is a managed relational database service provided by Microsoft. It can be used by applications that need structured data, such as customer accounts, products, orders, and transactions.

From my perspective, a managed database is helpful because developers can focus more on building the application instead of managing all of the physical database infrastructure themselves.

### 4. Azure Virtual Network

Azure Virtual Network allows Azure resources to communicate with each other in a private network environment. It can be used to organize resources and control network communication.

I think this service is important because cloud applications still need proper networking and security. Just like computers in a physical organization need a network, cloud resources also need a controlled networking environment.

## 5. Three Advantages

### 1. Strong Microsoft Integration

One of the biggest advantages of Azure is its integration with Microsoft technologies. Organizations that already use products such as Windows Server and Microsoft 365 may find Azure easier to integrate into their existing environment.

This is one reason why I think Azure is a strong choice for schools and businesses that already depend heavily on Microsoft products.

### 2. Global Infrastructure

Azure has a large global infrastructure with many regions and datacenters. This gives organizations more choices for deploying applications and storing data.

For global companies, this can be useful because they can choose locations that are appropriate for their users and business requirements.

### 3. Scalability and Flexibility

Azure allows organizations to choose different levels of computing, storage, networking, and other resources based on their needs. Resources can be adjusted as requirements change.

I think this is helpful for businesses because they may not need to purchase expensive physical hardware whenever their applications grow. Instead, they can use cloud resources and adjust them according to demand.

## 6. Typical Enterprise Use Cases

Microsoft Azure can be used by many different types of organizations. Some common enterprise use cases include:

* **Web application hosting** – Companies can deploy websites and web applications using Azure services.
* **Virtual machines** – Organizations can migrate Windows or Linux servers to Azure Virtual Machines.
* **Database management** – Businesses can use Azure SQL Database for applications that require relational databases.
* **File and data storage** – Azure Blob Storage can be used to store documents, images, videos, backups, and other data.
* **Hybrid cloud environments** – Organizations can connect existing on-premises infrastructure with Azure cloud resources.
* **Microsoft-based enterprise systems** – Companies already using Microsoft technologies can use Azure to extend their existing infrastructure.
* **Artificial intelligence and analytics** – Businesses can use Azure's AI and data services to develop intelligent applications and analyze information.

For example, a university that already uses Windows Server and Microsoft 365 could use Azure Virtual Machines for some of its servers, Azure SQL Database for applications, Azure Virtual Network for networking, and Microsoft Entra ID for identity and access management. This shows why Azure can be a practical option for organizations that already use Microsoft's technologies.

## My Understanding of Microsoft Azure

After researching Azure, I learned that it is more than just a place to host websites. It provides a complete set of cloud services that can support computing, storage, databases, networking, security, and business applications.

Personally, I think Azure is interesting because of its connection with Microsoft's existing technologies. As an IT student, learning Azure can help me understand how organizations can move from traditional servers to cloud infrastructure while still using technologies that they are already familiar with.

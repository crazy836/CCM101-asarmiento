# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services, or AWS, is a cloud computing platform created by Amazon. Based on my understanding, AWS allows companies and developers to use computing resources through the internet instead of buying and maintaining their own physical servers. It provides many different services that can be used to build websites, mobile applications, databases, storage systems, and other IT solutions.

What I find interesting about AWS is that users do not have to purchase a large amount of hardware before starting a project. They can choose the resources they need and increase them when their application becomes bigger. This can be useful for both small businesses and large companies.

## Global Infrastructure

AWS has a large global infrastructure made up of **Regions and Availability Zones**. AWS currently has 39 geographic Regions and 123 Availability Zones. An Availability Zone is a separate location inside an AWS Region that helps provide better reliability and availability for applications.

For me, this is important because if a company has an application that needs to stay online, it can distribute its resources across different Availability Zones. This can reduce the effect of problems that happen in one location.

## Cloud Management Console

The **AWS Management Console** is a web-based interface where users can manage their AWS resources. Instead of using only command-line commands, users can use the console to find services, create resources, check usage, manage accounts, and monitor their cloud environment.

As a student, I think the console is helpful because it gives a visual way to learn how cloud services work. It can also help beginners understand the different AWS services before they start using more advanced tools such as the AWS CLI.

## Four Core AWS Services

### 1. Amazon EC2

Amazon EC2 provides virtual servers in the cloud. I understand EC2 as a computer that we can create and use through the internet without physically owning the server. It can be used to run websites, applications, and other workloads. AWS also provides EC2 Auto Scaling to automatically increase or decrease computing capacity based on demand.

### 2. Amazon S3

Amazon S3 is an object storage service. It can be used to store files, images, videos, backups, and other types of data. I think S3 is useful because applications can store large amounts of data without depending on the storage capacity of a personal computer or physical server.

### 3. Amazon RDS

Amazon Relational Database Service (Amazon RDS) is a managed database service. It can help organizations run relational databases without having to manually manage all of the database infrastructure. This would be useful for applications that need to store information such as customer accounts, products, transactions, or school records.

### 4. Amazon VPC

Amazon Virtual Private Cloud (Amazon VPC) allows users to create a logically isolated virtual network in AWS. Users can configure IP address ranges, subnets, route tables, and network security.

I think VPC is important because cloud resources still need networking and security just like computers inside a physical organization.

## Three Advantages of AWS

### 1. Wide Range of Services

One major advantage of AWS is the large number of services available. AWS provides services for computing, storage, databases, networking, security, artificial intelligence, analytics, and many other areas.

### 2. Scalability

AWS makes it possible to increase or decrease cloud resources depending on the needs of an application. For example, a website that suddenly receives many users can use scaling services to handle the additional workload.

### 3. Global Infrastructure

AWS has infrastructure in many locations around the world. This gives organizations different options for where they want to deploy their applications and can help them improve availability and performance.

## Typical Enterprise Use Cases

AWS can be used by many types of organizations. Some common examples include:

* Hosting websites and web applications
* Developing mobile applications
* Storing company files and backups
* Running databases
* E-commerce applications
* Data analytics
* Artificial intelligence and machine learning
* Disaster recovery
* Enterprise application hosting

For example, an online shopping company could use **EC2** to run its application, **S3** to store product images, **RDS** for customer and transaction information, and **VPC** to organize and secure its network.

## My Understanding of AWS

After researching AWS, I think its biggest advantage is flexibility. There are many services available, but this can also make AWS confusing for beginners because there are so many choices.

As a college student studying Information Technology, I see AWS as an important technology to learn because cloud computing is becoming an important part of modern IT. Learning basic services such as EC2, S3, RDS, and VPC gives me a better idea of how real companies can build and manage applications without depending completely on physical servers.

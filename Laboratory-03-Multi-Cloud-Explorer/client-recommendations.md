# Client Recommendations

## Client A – Startup Company

**Recommended Cloud Platform: Amazon Web Services (AWS)**

I would recommend AWS because the startup has a limited budget but expects its mobile application to grow. I think AWS is a good choice because the company can start with the resources it needs and increase them as more users begin using the application. For the application, I would use **Amazon EC2** for computing, **Amazon S3** for storing images and files, and **Amazon RDS** for the database. These services can give the startup a basic cloud infrastructure that can grow with the business.

**Recommended Services:**

* Amazon EC2
* Amazon S3
* Amazon RDS

---

## Client B – University

**Recommended Cloud Platform: Microsoft Azure**

I would recommend Microsoft Azure because the university already uses Windows Server, Microsoft 365, and Active Directory. In my opinion, using Azure would make sense because the university is already familiar with Microsoft's technologies and can continue using them while moving some services to the cloud. The university could use **Azure Virtual Machines** for Windows Server workloads, **Microsoft Entra ID** for identity and access management, and **Azure SQL Database** for applications that need a relational database. Azure also supports Microsoft-based environments and can connect cloud resources with existing systems.

**Recommended Services:**

* Azure Virtual Machines
* Microsoft Entra ID
* Azure SQL Database

---

## Client C – AI Research Company

**Recommended Cloud Platform: Google Cloud**

I would choose Google Cloud for the AI research company because its main requirement is developing artificial intelligence and machine learning applications. I think Google Cloud is a good match because it provides services and infrastructure designed for AI and high-performance computing. The company could use **Vertex AI** for AI and machine learning, **Compute Engine** for virtual computing resources, and **Cloud Storage** for storing datasets and research files. It could also use **Google Kubernetes Engine (GKE)** if it needs to deploy containerized applications.

**Recommended Services:**

* Compute Engine
* Cloud Storage
* Google Kubernetes Engine (GKE)

---

## Client D – Global E-Commerce Company

**Recommended Cloud Platform: Amazon Web Services (AWS)**

I would recommend AWS for the global e-commerce company because it needs high availability and automatic scaling. Online shopping websites can receive a large number of users during sales and holidays, so I think the infrastructure should be able to handle sudden increases in traffic. The company could use **Amazon EC2** for its application servers, **Elastic Load Balancing** to distribute traffic, and **Amazon RDS** for its database. It could also use **Amazon S3** for product images and **EC2 Auto Scaling** to adjust computing resources when demand changes.

**Recommended Services:**

* Amazon EC2
* Elastic Load Balancing
* Amazon RDS

---

## My Overall Decision

| Client                       | Recommended Platform | My Main Reason                                          |
| ---------------------------- | -------------------- | ------------------------------------------------------- |
| Client A – Startup           | **AWS**              | Good scalability for a growing application              |
| Client B – University        | **Azure**            | Strong fit with existing Microsoft technologies         |
| Client C – AI Research       | **Google Cloud**     | Strong choice for AI and machine learning               |
| Client D – Global E-Commerce | **AWS**              | Good fit for scalable and highly available applications |

### My Understanding

After analyzing the four scenarios, I learned that there is no single cloud provider that is automatically the best for every client. My choice depends on what each organization already has and what it needs to accomplish. For me, the most important part of being a Cloud Solutions Consultant is understanding the client's problem first and then selecting the cloud services that can solve it.

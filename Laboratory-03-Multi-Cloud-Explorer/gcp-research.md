# Google Cloud Platform (GCP) Research

## 1. Brief Overview

Google Cloud Platform (GCP), now commonly called **Google Cloud**, is a cloud computing platform developed by Google. It provides different services that allow individuals, developers, and organizations to build, deploy, store, and manage applications using Google's cloud infrastructure.

Based on my understanding, Google Cloud is similar to AWS and Microsoft Azure because it provides virtual machines, storage, databases, networking, and other cloud services. However, I think Google Cloud stands out because of its connection to Google's technologies, especially in areas such as artificial intelligence, machine learning, data analytics, and Kubernetes.

As an Information Technology student, I find Google Cloud interesting because many modern applications are becoming more dependent on data and AI. Learning GCP can give me an idea of how large companies use cloud computing to process large amounts of information and run applications at a global scale.

## 2. Global Infrastructure

Google Cloud has a global infrastructure made up of **regions and zones**. As of July 2026, Google Cloud lists **43 regions and 130 zones** across the world. Google also has a global network that connects locations across more than 200 countries and territories.

A region is a geographic location where Google Cloud resources can be deployed, while zones are separate deployment areas within a region. Google recommends distributing workloads across multiple zones when high availability is important.

For me, the global infrastructure is important because an application may have users from different countries. If resources are deployed closer to users, it can help reduce latency. Using multiple zones can also help protect an application from problems affecting a single zone.

## 3. Cloud Management Console

The **Google Cloud Console** is a web-based graphical interface used to manage Google Cloud projects and resources. Through the console, users can create and manage resources such as virtual machines, storage, databases, networks, and Kubernetes clusters. Google also provides Cloud Shell and command-line tools for users who prefer working through commands.

As a student, I think the Google Cloud Console is useful because it gives me a visual way to understand cloud infrastructure. Instead of only reading about cloud services, I can see projects, resources, billing information, and other settings in one place.

I also think the console is useful for beginners because it provides a graphical interface before moving to more advanced tools such as the Google Cloud CLI.


### 1. Compute Engine

**Compute Engine** provides virtual machines that can run applications and workloads in Google Cloud.

I think of Compute Engine as a computer that exists in the cloud. Instead of purchasing a physical server, an organization can create a virtual machine and choose the computing resources it needs.

For example, a company could use Compute Engine to host a website or run a backend application.

### 2. Cloud Storage

**Cloud Storage** is an object storage service that can be used to store different types of data, including files, images, videos, and backups.

From my understanding, it works like online storage for applications and organizations, but it is designed to handle much larger amounts of data than normal personal storage.

For example, a mobile application could use Cloud Storage to save profile pictures, documents, or other files uploaded by users.

### 3. Cloud SQL

**Cloud SQL** is a managed relational database service in Google Cloud. It can be used for applications that need structured information such as customer accounts, products, transactions, or other records.

I think Cloud SQL is useful because developers can use a managed database instead of having to maintain an entire database server manually.

### 4. Google Kubernetes Engine (GKE)

**Google Kubernetes Engine (GKE)** is a managed Kubernetes service provided by Google Cloud.

I find GKE particularly interesting because Kubernetes is widely used for containerized applications. Instead of manually managing every part of a Kubernetes environment, organizations can use GKE to deploy and manage container-based workloads.

For me, this is one of the services that makes Google Cloud stand out because Google played an important role in the development of Kubernetes.

## 5. Three Advantages

### 1. Strong AI and Machine Learning Capabilities

One major advantage of Google Cloud is its focus on artificial intelligence and machine learning. Google provides cloud infrastructure and services designed for AI workloads, including access to Google's AI technologies.

I think this is especially useful for companies developing AI applications because they can use cloud resources instead of purchasing and maintaining their own high-performance hardware.

### 2. Strong Kubernetes and Container Support

Another advantage is Google's strong support for Kubernetes. GKE provides a managed environment for deploying containerized applications.

As an IT student, I think learning Kubernetes together with Google Cloud would be useful because modern software development increasingly uses containers and cloud-native technologies.

### 3. Global Network and Scalability

Google Cloud provides a global infrastructure with regions, zones, and a large network connecting locations around the world. This allows organizations to design applications for global users while considering performance and availability.

I think this is important for applications that may start small but eventually gain users from different countries. The organization can expand its cloud infrastructure as the application grows.

## 6. Typical Enterprise Use Cases

Google Cloud can be used by many types of organizations. Some typical enterprise use cases include:

* **Artificial Intelligence and Machine Learning** – Companies can develop and deploy AI and ML applications using Google Cloud services.
* **Data Analytics** – Organizations can process and analyze large amounts of business data.
* **Web Application Hosting** – Companies can deploy websites and application backends using Google Cloud infrastructure.
* **Containerized Applications** – Businesses can use GKE to deploy applications using Kubernetes and containers.
* **Database Systems** – Organizations can use Cloud SQL and other database services for application data.
* **File and Object Storage** – Companies can use Cloud Storage for files, backups, media, and other data.
* **Global Applications** – Businesses can distribute their applications across regions and zones to support users in different locations.

For example, an AI company could use **Compute Engine** for computing workloads, **Cloud Storage** for datasets, **Cloud SQL** for application information, and **GKE** for deploying containerized AI applications. This shows how multiple Google Cloud services can work together as one cloud-based system.

## My Understanding of Google Cloud

After researching Google Cloud, I learned that it is not only focused on hosting websites or virtual machines. It provides a wide range of services that can be used for application development, storage, databases, networking, data analytics, AI, and containerized applications.

Personally, I think Google Cloud is interesting because of its strong connection to AI, data, and Kubernetes. As an IT student, I believe learning these technologies can be useful because cloud computing is becoming more important in modern software development.

Compared with AWS and Azure, I would consider Google Cloud a strong option for organizations that focus heavily on AI, machine learning, data analytics, and cloud-native applications. However, I also learned that there is no single cloud provider that is automatically the best for every organization. The right choice depends on the company's requirements, existing technology, budget, and type of workload.
